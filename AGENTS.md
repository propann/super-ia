# Instructions permanentes pour les agents

1. Lire `docs/PROJECT_VISION.md`, `docs/ARCHITECTURE.md`, `docs/SECURITY.md` et `docs/ROADMAP.md` avant toute modification importante.
2. Ne jamais écrire directement sur `main`.
3. Une mission de code travaille dans une branche et, dès que possible, dans un worktree dédié.
4. Ne jamais envoyer `.env`, jetons, clés, cookies, bases de données ou données privées à un fournisseur distant.
5. Les API payantes sont désactivées par défaut. Aucune dépense ne peut être engagée sans budget explicite.
6. Aucun agent ne fusionne son propre travail. La fusion demande une validation humaine.
7. Ne jamais contourner les quotas, CAPTCHA, limitations de comptes ou conditions d'utilisation d'un fournisseur.
8. Les commandes destructrices, l'élévation de privilèges et les modifications hors périmètre sont interdites sans validation explicite.
9. Chaque livraison indique les fichiers modifiés, tests exécutés, résultats, limites et risques.
10. Préserver les changements existants de l'utilisateur.
