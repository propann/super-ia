# Stratégie fournisseurs

## Priorité 1 — abonnements et comptes déjà disponibles

- OpenAI Codex CLI avec connexion ChatGPT ;
- Mistral Vibe avec plan Mistral ou modèle local ;
- Claude Code avec abonnement Claude compatible ;
- GitHub Copilot selon le plan du compte ;
- outils Google lorsque le compte et les conditions d'accès le permettent.

## Priorité 2 — agents ouverts

- Qwen Code ;
- OpenCode ;
- Aider ;
- Goose ;
- futurs agents respectant le contrat commun.

Ces outils ne rendent pas forcément le modèle gratuit. Ils servent de prises universelles vers une offre fixe, un endpoint bon marché ou un modèle local.

## Priorité 3 — web assisté

DeepSeek, Le Chat et d'autres interfaces peuvent recevoir un paquet de contexte préparé. L'utilisateur valide l'envoi et importe la réponse. Super IA n'automatise ni CAPTCHA, ni création de comptes, ni extraction interdite.

## Priorité 4 — API plafonnée

Les API compatibles sont des solutions de secours. Elles restent désactivées par défaut, avec budget mensuel, limite par mission et confirmation humaine.

## Donnée dynamique

Les quotas, modèles et conditions changent souvent. Le registre fournit une indication, mais la commande `doctor` devra progressivement interroger uniquement les mécanismes officiels disponibles localement au lieu de promettre un quota fixe.
