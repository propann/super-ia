# Vision — Super IA

Super IA est un centre de commandement local pour agents de développement. Il transforme une demande en missions isolées, attribue chaque mission au fournisseur le plus adapté, contrôle les coûts, protège les secrets, lance les tests et présente les changements avant toute intégration.

## Objectifs

- utiliser les abonnements et offres gratuites déjà disponibles avant toute API payante ;
- intégrer plusieurs CLI officielles sans dépendance à une marque ;
- accepter les agents open source, modèles locaux et interfaces web assistées ;
- travailler avec Git, branches et worktrees ;
- conserver une trace complète de chaque décision ;
- comparer les résultats de plusieurs IA lorsque le risque le justifie ;
- rester utilisable par une personne qui ne veut pas administrer une usine à gaz.

## Refus

- création industrielle de comptes ;
- contournement de quotas, CAPTCHA ou limitations ;
- scraping interdit des interfaces web ;
- envoi silencieux d'un dépôt privé ;
- dépense API non plafonnée ;
- fusion autonome vers `main` ;
- confusion entre une suggestion d'IA et une validation par les tests.
